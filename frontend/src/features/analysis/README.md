Pestañas para tokens, árbol, símbolos y diagnósticos. Mostrar los resultados reales
de la API; no simular una compilación exitosa con datos de muestra.

horarios grandes. Usar `ast.children`, IDs y rangos del contrato v1 para enlazar
cada nodo con el editor. La vista no se limita a imprimir la estructura JSON.
Esquemas y ejemplos ilustrativos: `contracts/`, en la raíz del repositorio.
